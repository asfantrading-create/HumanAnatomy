# Human Anatomy 3D: Unity + VR edition (ASFAN)

This is the Unity 6 version of the program. It shows the same high-detail male and female bodies (4.17 million triangles, 2,269 structures), in Arabic and English. It runs on the desktop and can switch to a PC VR headset (Meta Quest 3 through Quest Link / Air Link).

> **Arabic step-by-step guide:** see the "دليل التشغيل" section below.

## Folder contents

| Path | Contents |
|---|---|
| `Assets/StreamingAssets/anatomy.bin`, `anatomy.json` | The model, generated by `tools/export_unity.mjs` |
| `Assets/StreamingAssets/voice/` | Arabic pronunciations. The Setup menu copies them from `../src/assets/voice` (not in git) |
| `Assets/Resources/*.shader` | The structure shader (lighting, sections, blood flow, muscle fibres), the floor and lasers |
| `Assets/Scripts/Runtime/` | The program: loading, interface, picking, Arabic text, voice, VR |
| `Assets/Scripts/Editor/ProjectSetup.cs` | Automatic setup (OpenXR, scene, player settings) and the Windows build |

Render pipeline: Built-in (no URP needed). XR: OpenXR 1.18 with the Oculus Touch / Meta Quest Touch Plus controller profiles.

## Regenerating the model (optional)

```bash
python3 tools/convert_bp3d.py <BodyParts3D folder> <out> 4000000
node scripts/vendor.js
node tools/export_unity.mjs <out> unity/Assets/StreamingAssets
```

## دليل التشغيل (بالعربية)

### أولاً: المتطلبات
1. **Unity Hub** مع المحرر **Unity 6000.3.26f1**، وهو مثبت لديك أصلاً. أضف من Hub ‏← Installs ‏← ⚙ ‏← Add modules الوحدة **Windows Build Support (Mono)** إن لم تكن موجودة، فهي لازمة لإنشاء ملف exe فقط.
2. تطبيق **Meta Quest Link** على الكمبيوتر (اسمه سابقاً Oculus). حمّله من: https://www.meta.com/quest/setup/
3. كرت شاشة يدعم Quest Link، مثل NVIDIA GTX 1070 أو أعلى، أو ما يكافئه من AMD.

### ثانياً: تنزيل المشروع
1. نزّل الفرع `claude/3d-anatomy-windows-app-s829hk` من GitHub، إما بـ `git clone` أو بـ Code ‏← Download ZIP.
2. أبقِ مجلد المستودع كاملاً كما هو. الإعداد ينسخ ملفات الصوت من `src/assets/voice` الموجود بجانب مجلد `unity`.

### ثالثاً: فتح المشروع في Unity
1. افتح **Unity Hub** ‏← **Projects** ‏← **Add** ‏← **Add project from disk**.
2. اختر المجلد **`unity`** الموجود داخل المستودع، وليس المجلد الرئيسي.
3. إذا طلب Hub اختيار نسخة المحرر فاختر **6000.3.26f1**، ثم افتح المشروع.
4. سيستغرق الفتح الأول عدة دقائق لأن Unity ينزّل حزم OpenXR وInput System ويستورد النموذج.
5. إذا ظهرت رسالة عن **Input System / Enable backends** فاختر **Yes**. سيُعاد تشغيل المحرر، والبرنامج يعمل مع الخيارين.
6. بعد الفتح يعمل **الإعداد التلقائي** وحده، وتظهر رسالة "Setup finished". إذا لم تظهر، شغّله يدوياً من القائمة:
   **Tools ‏← ASFAN Anatomy ‏← Setup Project**
   
   ينفّذ الإعداد ما يلي:
   - ضبط اسم الشركة ASFAN واسم المنتج والأيقونة ونظام Windows 64-bit.
   - تفعيل **OpenXR** للكمبيوتر، مع إيقاف "التشغيل التلقائي للـ VR"، لأن البرنامج يفتح على الشاشة أولاً.
   - تفعيل ملفّي يدَي التحكم **Oculus Touch** و**Meta Quest Touch Plus** الخاصين بـ Quest 3.
   - إنشاء المشهد `Assets/Scenes/Main.unity` وإضافته للبناء.
   - نسخ 2,457 ملفاً صوتياً لنطق الأسماء بالعربية.

### رابعاً: التحقق من إعدادات الـ VR (مرة واحدة)
افتح **Edit ‏← Project Settings ‏← XR Plug-in Management** وتأكد من التالي:
- في تبويب **Windows** (أيقونة الشاشة) تكون علامة ✔ أمام **OpenXR**.
- خيار **Initialize XR on Startup** يكون **غير مفعّل**.
- في صفحة **OpenXR** الفرعية تظهر ضمن **Enabled Interaction Profiles** العناصر **Oculus Touch Controller Profile** و**Meta Quest Touch Plus Controller Profile**. إن لم تظهر فأضفها بزر **+**.
- إذا ظهر مثلث أصفر أو أحمر في **Project Validation** فاضغط **Fix All**.

### خامساً: تجهيز النظارة Quest 3
1. شغّل تطبيق **Meta Quest Link** على الكمبيوتر وسجّل الدخول.
2. من **Settings ‏← General** اضغط **OpenXR Runtime ‏← Set Meta Quest Link as active**. هذه الخطوة مهمة جداً.
3. في نفس الصفحة فعّل **Unknown sources** حتى يُسمح للبرنامج بالعمل على النظارة.
4. وصّل النظارة:
   - **سلكياً:** بكيبل USB-C، ثم من داخل النظارة: Quick Settings ‏← **Link** ‏← Launch.
   - **أو لاسلكياً:** من داخل النظارة: Quick Settings ‏← **Air Link** ‏← اختر الكمبيوتر.
5. يجب أن تظهر داخل النظارة واجهة Link، وهي غرفة رمادية/زرقاء فيها شريط القوائم.

### سادساً: التشغيل
1. في Unity اضغط زر **Play ▶** في الأعلى. يحمّل البرنامج النموذج ويفتح على الشاشة.
2. في الشريط العلوي تظهر حالة النظارة:
   - **"النظارة متصلة وجاهزة":** يصبح زر **"دخول الواقع الافتراضي"** الأخضر فعّالاً.
   - **"النظارة غير متصلة":** يعيد البرنامج البحث تلقائياً كل 10 ثوانٍ، ويمكنك الضغط على **"بحث"**.
3. اضغط **"دخول الواقع الافتراضي"** ثم ضع النظارة. ستجد نفسك واقفاً أمام الجسم على بعد 1.3 متر.
4. للخروج اضغط **"الخروج من الواقع الافتراضي"**، إما من الشاشة أو من قائمة اليد داخل النظارة.

### سابعاً: التحكم داخل النظارة
| الزر | الوظيفة |
|---|---|
| **الزناد الأيمن** (Trigger) | اختيار عضو بالليزر، فيظهر اسمه ويُنطق بالعربية، أو الضغط على أزرار القائمة |
| **القبضة** (Grip) بيد واحدة | إمساك الجسم وتحريكه وتدويره |
| **القبضتان معاً** | تكبير/تصغير الجسم وتدويره، فيمكن تكبيره ليصبح بحجم غرفة والدخول إليه |
| **عصا اليسار** | المشي |
| **عصا اليمين** (يمين/يسار) | الالتفاف 30° |
| **X** | إظهار/إخفاء قائمة اليد اليسرى |
| **Y** | إعادة الجسم لمكانه |
| **A** | نطق اسم العضو المختار |
| **B** | إخفاء العضو المختار |
| **الضغط على عصا اليمين** | تثبيت/تحريك المقطع اليدوي |

قائمة اليد تحتوي على:
- الأجهزة الـ12.
- رجل/امرأة، أشعة سينية، إظهار الكل.
- نبض القلب، التنفس، جريان الدم، التفكيك.
- **مقطع باليد:** لوح شفاف في يدك يقطع الجسم أينما وجّهته.
- تثبيت المقطع، تكبير/تصغير، اللغة، والخروج.

### ثامناً: التحكم على الشاشة
- زر الفأرة الأيسر للتدوير، والأيمن للتحريك، والعجلة للتكبير.
- النقر يختار العضو، والنقر المزدوج يقرّب الكاميرا عليه.
- المفاتيح: **H** إخفاء، **F** تركيز، **X** أشعة سينية، **R** إعادة العرض، **Esc** إلغاء الاختيار.
- اللوحة الجانبية فيها:
  - الأجهزة مع شفافية كل جهاز.
  - رجل/امرأة.
  - المقاطع الثلاثة مع زر "عكس".
  - التفكيك، والنبض، والتنفس، وجريان الدم.
- لوحة المعلومات فيها: الاسم بالعربية والإنجليزية، الوصف، نطق الاسم، عزل العضو، وتصفّح كل الأعضاء حسب المنطقة.
- الشريط العلوي: تبديل اللغة، والوضع الفاتح/الداكن.

### تاسعاً: إنشاء ملف exe للبيع
1. من القائمة: **Tools ‏← ASFAN Anatomy ‏← Build Windows Program**، ثم اختر مجلد الإخراج.
   أو بالطريقة العادية: **File ‏← Build Profiles ‏← Windows ‏← Build**.
2. الناتج مجلد فيه `HumanAnatomy3D.exe`، ومعه المجلد `HumanAnatomy3D_Data` و`UnityPlayer.dll`. **انسخ المجلد كاملاً** للعميل.
3. على جهاز العميل: يعمل البرنامج على الشاشة مباشرة. ولاستخدام النظارة يحتاج العميل فقط إلى تطبيق Meta Quest Link، مع ضبط OpenXR Runtime عليه كما في الخطوة الخامسة.

### حل المشاكل
| المشكلة | الحل |
|---|---|
| "النظارة غير متصلة" مع أن النظارة موصولة | تأكد أن Link يعمل داخل النظارة، وأن **OpenXR Runtime = Meta Quest Link**، ثم اضغط "بحث" |
| تعذّر تشغيل الواقع الافتراضي | أغلق SteamVR إن كان مفتوحاً، وأعد تشغيل تطبيق Link |
| ملف النموذج غير موجود | تأكد من وجود `Assets/StreamingAssets/anatomy.bin` (حوالي 51 ميغابايت) |
| لا يُنطق الاسم | شغّل **Setup Project** مرة أخرى لنسخ ملفات الصوت |
| أخطاء حمراء في Console بعد الفتح الأول | انتظر انتهاء الاستيراد ثم أعد تشغيل المحرر، وشغّل **Setup Project** |
| الصورة في النظارة بطيئة | في تطبيق Link: Devices ‏← Quest 3 ‏← Graphics Preferences، وخفّض Refresh rate إلى 72Hz |

### ما سيُنقل لاحقاً من النسخة السابقة (Electron)
الدروس والجولات، والاختبارات والشهادات، والتقدّم والملاحظات، ونظام الترخيص والفترة التجريبية (5 أيام). هذه الأجزاء موجودة حالياً في نسخة Electron، وستُضاف إلى نسخة Unity في المرحلة التالية.
