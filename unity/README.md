# Human Anatomy 3D – Unity + VR edition (ASFAN)

This is the Unity 6 version of the program. It covers everything in the Electron desktop edition, and adds PC VR on a Meta Quest 3 through Quest Link / Air Link.

The model has 2,269 male and female structures and 4.17 million triangles.

What it includes:

- **Exploring:** 12 systems with an opacity slider each, male and female bodies, X-ray, and explode.
- **Viewing:** three section planes, automatic labels, search, isolate, hide and undo, preset views, auto rotation, and screenshots.
- **Physiology:** heartbeat, breathing, blood flow and cardiac conduction.
- **Voice:** Arabic pronunciation of names, and Windows speech for explanations.
- **Learning centre:**
  - 13 lessons at school and university level.
  - Teacher mode: lesson files that are compatible with the Electron edition, and a presentation mode.
  - A quick quiz with *Name it* and *Find it* modes.
  - A comprehensive exam with a timer and a **PDF certificate**.
  - Progress tracking, favourites, notes and saved views.
- **Licensing:** a 5-day trial and signed licence keys. These are the **same keys and generator** as the Electron edition (`tools/license-generator.html`), with machine binding and institution licences.
- **VR:** automatic headset detection, laser selection, grab and two-hand scaling, walking, a hand menu with lessons, and a hand-held section plane.

> **The Arabic guide (setup and building the exe) is in the "الدليل بالعربية" section below.**

## Folder contents

| Path | Contents |
|---|---|
| `Assets/StreamingAssets/anatomy.dat`, `anatomy.idx`, `learning.dat` | The model, names and descriptions, lessons, questions and interface text. They are **encrypted** (AES-256) and generated by `tools/export_unity.mjs` |
| `Assets/StreamingAssets/voice/` | Arabic pronunciations. The Setup menu copies them from `../src/assets/voice` (not stored in git) |
| `Assets/StreamingAssets/EULA.txt`, `asfan-logo.png` | Licence agreement and logo |
| `Assets/Resources/*.shader` | Shaders for the structures, labels (object ids), floor and lasers |
| `Assets/Scripts/Runtime/` | The program |
| `Assets/Scripts/Editor/ProjectSetup.cs` | Automatic setup, the Windows build and the installer |
| `Installer/` | Inno Setup script, icon and the licence page of the installer |
| `Builds/` | Build output (not stored in git) |

Render pipeline: Built-in. XR: OpenXR 1.18 with the Oculus Touch and Meta Quest Touch Plus profiles.

### Regenerating the data (only after changing the model, names or lessons)
```bash
python3 tools/convert_bp3d.py <BodyParts3D folder> <out> 4000000
node scripts/vendor.js
node tools/export_unity.mjs <out> unity/Assets/StreamingAssets
```

# الدليل بالعربية

## الجزء الأول: تجهيز جهازك (مرة واحدة)

1. **Unity Hub** مع المحرر **Unity 6000.3.26f1**، وهو مثبت لديك.
2. **البناء لويندوز مدمج في المحرر** على أجهزة ويندوز، فلا تحتاج إضافة وحدة له (لا تظهر وحدة باسم Mono في القائمة).
   وحدة **Windows Build Support (IL2CPP)** اختيارية، وهي للبناء المحمي (انظر الجزء الخامس).
3. **Inno Setup 6** (مجاني) لإنشاء ملف تثبيت `Setup.exe` واحد: https://jrsoftware.org/isdl.php
   ثبّته بالإعدادات الافتراضية، وسيكتشفه البرنامج تلقائياً.
4. **Meta Quest Link** على الكمبيوتر، وهو مطلوب لتجربة النظارة فقط: https://www.meta.com/quest/setup/

## الجزء الثاني: فتح المشروع

1. نزّل الفرع `claude/3d-anatomy-windows-app-s829hk` من GitHub: **Code ← Download ZIP**، ثم فك الضغط.
   أبقِ المجلد كاملاً، لأن ملفات الصوت موجودة في `src/assets/voice` خارج مجلد `unity`.
2. افتح Unity Hub ← **Projects** ← **Add** ← **Add project from disk** ← اختر المجلد **`unity`**.
3. افتح المشروع بالنسخة **6000.3.26f1**. الفتح الأول يأخذ من 5 إلى 15 دقيقة.
4. إذا ظهرت رسالة **Enable Input System backends** فاختر **Yes**، وسيُعاد تشغيل المحرر.
5. بعد الفتح يعمل **الإعداد التلقائي** وتظهر رسالة **Setup finished**. إذا لم تظهر فشغّله من:
   **Tools ← ASFAN Anatomy ← Setup Project**
6. تحقّق مرة واحدة من **Edit ← Project Settings ← XR Plug-in Management**:
   - في تبويب Windows توجد علامة ✔ أمام **OpenXR**.
   - خيار **Initialize XR on Startup** غير مفعّل.
   - إذا ظهر تحذير في **Project Validation** فاضغط **Fix All**.

## الجزء الثالث: التجربة داخل Unity

- اضغط **Play ▶**. يحمّل البرنامج النموذج، ثم يسألك: رجل أم امرأة.
- **المكتبة التعليمية:** من زر **"مركز التعلّم"** في الشريط السفلي، وفيه:
  - الدروس.
  - الامتحان.
  - تقدّمي.
  - المفضلة.
- **الاختبار السريع:** زر **"اختبار سريع"**.
- **وضع العرض للصف:** زر **"وضع العرض"**.
- **الترخيص:** الزر الملوّن في الأعلى، ويظهر عليه "نسخة تجريبية · 5 يوم".
- **النظارة:** شغّل Link في النظارة، ثم اضغط **"دخول الواقع الافتراضي"**.
- في المحرر تُحفظ البيانات في:
  `%USERPROFILE%\AppData\LocalLow\ASFAN\Human Anatomy 3D`
  وتشمل الترخيص والتقدّم.

## الجزء الرابع: بناء البرنامج (exe + ملف التثبيت)

### الطريقة المختصرة (ننصح بها)
1. في Unity من القائمة العلوية: **Tools ← ASFAN Anatomy ← Build Windows Program**.
2. انتظر حتى ينتهي البناء. يأخذ أول بناء من 5 إلى 15 دقيقة، والبناءات اللاحقة أسرع.
3. تظهر رسالة فيها مكان الملفات، ويُفتح المجلد تلقائياً:
   - **البرنامج:** `unity/Builds/HumanAnatomy3D/HumanAnatomy3D.exe`، ومعه المجلد `HumanAnatomy3D_Data` وملفات dll.
   - **ملف التثبيت:** `unity/Builds/Installer/HumanAnatomy3D-VR-Setup-6.0.0.exe`. يُنشأ فقط إذا كان Inno Setup مثبتاً.
4. **هذا ملف التثبيت هو الذي ترسله للعميل.** هو ملف واحد بحجم 150 إلى 250 ميغابايت تقريباً، ويقوم بما يلي:
   - يعرض اتفاقية الترخيص.
   - يثبّت البرنامج في `C:\Program Files\ASFAN\Human Anatomy 3D`.
   - ينشئ اختصاراً على سطح المكتب وفي قائمة ابدأ.
   - يضيف برنامج إزالة التثبيت.

### الطريقة اليدوية (من دون القائمة)
1. **File ← Build Profiles** ← اختر **Windows** ← **Switch Platform** إن لزم.
2. تأكد أن `Assets/Scenes/Main.unity` موجود في قائمة **Scene List**.
3. اضغط **Build**، ثم اختر مجلداً فارغاً واكتب الاسم `HumanAnatomy3D`.
4. لإنشاء ملف التثبيت يدوياً:
   - افتح الملف `unity/Installer/HumanAnatomy3D.iss` في Inno Setup.
   - غيّر `SourceDir` إلى مجلد البناء.
   - اضغط **Build ← Compile**.

### بدون ملف تثبيت
يمكنك ضغط المجلد `unity/Builds/HumanAnatomy3D` كاملاً بصيغة ZIP وإرساله. يفك العميل الضغط ويشغّل `HumanAnatomy3D.exe`.
**لا ترسل ملف exe وحده**، فهو لا يعمل من دون مجلد `_Data` والملفات المرافقة.

### رفع رقم الإصدار
عدّل `AppVersion` في الملف `Assets/Scripts/Editor/ProjectSetup.cs`، مثلاً "6.0.1"، ثم ابنِ من جديد. سيحمل ملف التثبيت الرقم الجديد، ويثبَّت فوق النسخة القديمة.

## الجزء الخامس: حماية البرنامج (مهم للبيع)

1. **بيانات النموذج مشفّرة:** لا يستطيع أحد نسخ النماذج أو الأسماء أو الأوصاف أو الأسئلة من مجلد البرنامج المثبَّت.
2. **مفتاح التحقق من الترخيص مدمج في الكود.** لا يمكن استبدال المفتاح لتزوير ترخيص.
3. **الحماية الأقوى:** ابنِ من **Tools ← ASFAN Anatomy ← Build Windows Program (IL2CPP - protected code)**.
   - هذا البناء يحوّل كود C# إلى كود آلة، فيصبح فكّه أصعب بكثير.
   - يحتاج وحدة **Windows Build Support (IL2CPP)**.
   - ويحتاج **Visual Studio 2022 Community** مع **Desktop development with C++**.
   - عند تثبيت Unity عبر Hub يمكنك اختيار Visual Studio من نفس الشاشة.

## الجزء السادس: إصدار مفاتيح الترخيص للعملاء

نفس الطريقة المتبعة مع نسخة Electron، وبنفس الأداة:

1. يرسل لك العميل **معرّف الجهاز** من نافذة الترخيص، وفيها زر "نسخ" وزر واتساب جاهز.
2. افتح `tools/license-generator.html` مع ملف المفتاح الخاص `private.jwk.json`. هذا الملف لا يُرفع أبداً، واحفظه في مكان آمن مع نسخة احتياطية.
3. أنشئ المفتاح: شهري أو سنوي، أو لعدة أجهزة لمؤسسة، أو للموظفين.
4. أرسل المفتاح `HA3D1-…` أو ملف `.lic` للعميل. يلصقه في **نافذة الترخيص ← تفعيل الترخيص**.

**المفاتيح الحالية تعمل في النسختين**، لأن معرّف الجهاز يُحسب بنفس الطريقة.

## الجزء السابع: ما يحتاجه جهاز العميل
- **النظام:** Windows 10 أو 11 بنظام 64-bit.
- **كرت الشاشة:** يدعم DirectX 11. للنظارة يُفضَّل GTX 1070 / RTX 2060 أو أعلى.
- **الذاكرة:** RAM بسعة 8 GB، والأفضل 16 GB.
- **للواقع الافتراضي:** Quest 2 أو 3 أو Pro، مع تطبيق Meta Quest Link. ومن الإعدادات: **OpenXR Runtime = Meta Quest Link**، وتفعيل **Unknown sources**.
- **الشرح الصوتي لنصوص الدروس:** يستخدم صوت ويندوز. للعربية يجب تثبيت صوت عربي من:
  Settings ← Time & Language ← Speech ← Add voices ← Arabic.
  أسماء الأعضاء مسجّلة مسبقاً ولا تحتاج ذلك.

## الجزء الثامن: إصدار تحديث تلقائي للعملاء

عند فتح البرنامج يبحث تلقائياً عن إصدار أحدث، فإذا وجده يعرض نافذة فيها «تحديث الآن» و«لاحقاً». بعد الموافقة:
1. يُنزَّل ملف التثبيت الجديد.
2. يُتحقَّق من توقيع أصفان ومن سلامة الملف.
3. يُثبَّت التحديث، ثم يُفتح البرنامج من جديد.

**التجهيز (مرة واحدة):**
أنشئ مستودعاً **عاماً (Public)** على GitHub باسم `HumanAnatomy-Updates`، يكون فارغاً، ويستخدم فقط لنشر ملفات التثبيت.

**عند كل تحديث:**
1. ارفع رقم `AppVersion` في `Assets/Scripts/Editor/ProjectSetup.cs`، مثلاً 6.0.1، ثم ابنِ البرنامج.
2. افتح `tools/license-generator.html` ← القسم **4 · نشر تحديث للبرنامج**:
   - اكتب رقم الإصدار.
   - اختر ملف التثبيت الجديد.
   - اكتب ملاحظات التحديث.
   - اضغط **إنشاء ملف التحديث**، فيُنزَّل `update.json`.
3. في GitHub افتح مستودع `HumanAnatomy-Updates` ← **Releases** ← **Draft a new release**:
   - **Tag:** `v6.0.1`
   - **Title:** `6.0.1`
   - اسحب ملف التثبيت وملف `update.json` إلى خانة الملفات، ثم اضغط **Publish release**.
4. انتهيت. كل عميل يفتح البرنامج سيظهر له التحديث. يمكن أيضاً التحقق يدوياً من **الإعدادات ← التحقق من وجود تحديث**.

> إذا كتبت في خانة «أقل إصدار يجب تحديثه» رقماً أكبر من إصدار العميل، يصبح التحديث إجبارياً، ولا يظهر زر «لاحقاً».
