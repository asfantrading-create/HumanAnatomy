# Human Anatomy 3D – التشريح ثلاثي الأبعاد

برنامج ويندوز تعليمي تفاعلي لتشريح جسم الإنسان كاملاً بالأبعاد الثلاثية، بواجهة عربية وإنجليزية، ويعمل دون إنترنت.

## المزايا

- **نماذج تشريحية حقيقية عالية الدقة:** أكثر من 2,200 جزء من قاعدة بيانات BodyParts3D، وهي نماذج مأخوذة من تصوير طبي حقيقي، مع جزء أصغر من الأجزاء مكمَّل بنماذج مبسطة.
- **12 جهازاً:** الجلد، والهيكل العظمي، والعضلات، والعصبي، والقلب والأوعية، واللمفاوي، والتنفسي، والهضمي، والبولي، والتناسلي، والغدد الصماء، وأعضاء الحس.
- **تقسيم تشريحي:** فصوص الدماغ ملوّنة كل فص بلون (جبهي، جداري، صدغي، قذالي، حوفي)، وحجرات القلب وصماماته من الداخل، وفصوص الرئتين، وتقسيم بحسب المنطقة.
- **مقاطع تشريحية:** سهمية وإكليلية ومستعرضة، مع إمكانية عكس اتجاه كل منها.
- **حركة حية:** نبض القلب وتنفّس الرئتين وحركة الحجاب الحاجز.
- **لغتان:** واجهة كاملة بالعربية والإنجليزية، مع اسم ووصف لكل جزء باللغتين.
- **النطق الصوتي:** نطق أسماء الأعضاء وأوصافها.
- **6 دروس تفاعلية:** القلب، والدماغ، والتنفس، والهضم، والهيكل، والجهاز اللمفاوي.
- **اختبار بنمطين:** «سمِّ الجزء» و«أوجد الجزء».
- **أدوات أخرى:** البحث، والعزل، والإخفاء والتراجع، ووضع الأشعة، وتفكيك الأجزاء، والتسميات التلقائية، وحفظ لقطة شاشة.
- **جسم الرجل وجسم المرأة:** يختار المستخدم أحدهما عند البدء، ويمكنه التبديل بينهما من زر ♂/♀. جسم المرأة مبني من النموذج الحقيقي بعد تعديل أبعاده، مع رحم ومبيضين وقناتي فالوب ومهبل وغدد ثديية مبسّطة.
- **صوت عربي احترافي:** أسماء كل الأجزاء، وشرح الدروس، وأوصاف الأعضاء الرئيسية مسجّلة مسبقاً بصوت «عبدالله» من ElevenLabs، فتعمل دون إنترنت. ما لم يُسجَّل يُقرأ بصوت ويندوز.
- **تكبير الخط وتصغيره (+A و-A)، وخلفية فاتحة أو داكنة**، ويحفظ البرنامج اختيار المستخدم.
- **نظام تراخيص:** اشتراك شهري أو سنوي بمفاتيح موقّعة مربوطة بجهاز العميل، مع فترة تجريبية مدتها 5 أيام وأداة لتوليد المفاتيح.
- **التواصل:** واتساب ‎+962776140404، والبريد الإلكتروني info@asfanco.com.
- **اتفاقية ترخيص (EULA):** بالعربية والإنجليزية في `EULA.txt`. تظهر في المثبّت قبل التثبيت، ويمكن فتحها من داخل البرنامج.

## التحميل

كل دفعة (push) تشغّل GitHub Actions، فيبني البرنامج على ويندوز. لتحميله افتح تبويب **Actions** ثم **Build Windows EXE**، وحمّل الملف المرفق **HumanAnatomy3D-windows**. بداخله نسخة محمولة (portable) ومثبّت (setup).

## نظام التراخيص (اشتراك شهري أو سنوي)

يعمل نظام التراخيص دون إنترنت ودون أي خادم، بمفاتيح موقّعة رقمياً بخوارزمية ECDSA P-256:

1. عند أول تشغيل تبدأ **فترة تجريبية مدتها 5 أيام**. بعد انتهائها يظهر للمستخدم **معرّف الجهاز** (مثل `DDC5-498C-8050-9905`)، مع زرّي تواصل عبر واتساب والبريد الإلكتروني.
2. يرسل العميل معرّف جهازه. افتح `tools/license-generator.html` في المتصفح وحمّل فيه ملف المفتاح الخاص `private.jwk.json`، ثم أدخل اسم العميل ونوع الاشتراك (شهري أو سنوي أو تاريخ مخصص) ومعرّف الجهاز.
3. أرسل للعميل المفتاح الناتج `HA3D1-...` أو ملف `.lic`. يفعّله العميل من نافذة الترخيص 🔑، فيعمل حتى تاريخ الانتهاء المكتوب فيه، وعلى جهازه فقط.

- **ترخيص الموظفين:** يوجد خيار داخلي لإصدار ترخيص بلا تاريخ انتهاء.
- **المفتاح الخاص سري:** لا يوجد في المستودع ولا يُرسل للعملاء. من يملكه يستطيع إصدار تراخيص.
- **المفتاح العام:** موجود في `license-public.jwk.json`، ويستخدمه البرنامج للتحقق من التراخيص.
- **تعطيل النظام:** ضع `"enabled": false` في الملف `licensing.config.json`.

## التشغيل من المصدر

```bash
npm install
npm start          # تشغيل البرنامج
npm run dist       # بناء ملفات exe (يحتاج ويندوز أو Wine لبناء المثبّت)
```

### إعادة توليد النماذج من المصدر

```bash
# 1) حمّل isa_BP3D_4.0_obj_99.zip وpartof_BP3D_4.0_obj_99.zip وملفات القوائم (*.txt) من BodyParts3D، وفك ضغطها في مجلد
pip install numpy fast-simplification scipy trimesh
python3 tools/bp3d_index.py <bp3d_dir>
python3 tools/convert_bp3d.py <bp3d_dir> <out_dir>   # ينتج anatomy.bin وanatomy-parts.json
python3 tools/merge_i18n.py                          # يدمج الأسماء والأوصاف العربية والإنجليزية
```

### إعادة توليد التسجيلات الصوتية

مفتاح ElevenLabs لا يُحفظ في المستودع ولا يُضمَّن في البرنامج، وإنما يُمرَّر عبر متغير البيئة `ELEVENLABS_API_KEY`:

```bash
ELEVENLABS_API_KEY=... python3 tools/tts_elevenlabs.py jobs.json --budget 30000
```

حيث يحتوي `jobs.json` على قائمة بالصيغة `[{"text": "..."}]`. ينتج الأمر ملفات `src/assets/voice/*.mp3` ويحدّث الملف `src/assets/voice.json`.
