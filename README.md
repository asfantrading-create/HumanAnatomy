# Human Anatomy 3D – التشريح ثلاثي الأبعاد

برنامج ويندوز تعليمي تفاعلي لتشريح جسم الإنسان كاملاً بالأبعاد الثلاثية، بواجهة عربية وإنجليزية، ويعمل دون إنترنت.

## المزايا

### الاستكشاف
- **نماذج تشريحية حقيقية:** أكثر من 2,200 جزء من BodyParts3D، موزعة على 12 جهازاً.
- **جسم الرجل وجسم المرأة:**
  - جسم المرأة مشتق من النموذج الحقيقي، بملامح وجه أنثوية وعينين وحاجبين رفيعين وشعر طويل يتبع شكل فروة الرأس.
  - فيه ثديان مع الهالة، وحوض وأرداف أعرض، وسطح أملس للأعضاء الخارجية.
  - فيه أعضاء تناسلية أنثوية داخلية: الرحم وعنقه والمبيضان وقناتا فالوب والمهبل.
- **مقاطع تشريحية** سهمية وإكليلية ومستعرضة.
- **أدوات العرض:** وضع الأشعة، وتفكيك الأجزاء، والتسميات التلقائية، والبحث، والعزل.
- **محاكاة وظائف الأعضاء:**
  - نبض القلب، وتنفّس الرئتين.
  - **تدفق الدم:** موجات حمراء في الشرايين مبتعدة عن القلب، وزرقاء في الأوردة عائدة إليه.
  - **التوصيل الكهربائي في القلب:** موجة تنطلق من العقدة الجيبية الأذينية.

### التعلّم (مركز التعلّم 📚)
- **13 درساً تفاعلياً** على مستويين، مدرسي وجامعي، مع شرح صوتي عربي.
- **امتحان شامل:**
  - يجمع أسئلة مفاهيمية مكتوبة يدوياً، وأسئلة تعرّف على الأجزاء في النموذج، وأسئلة من الأوصاف.
  - يتيح اختيار الأجهزة المشمولة وعدد الأسئلة والوقت.
  - **يمنح شهادة إتمام PDF** باسم الطالب وشعار أصفان عند النجاح بنسبة 70% فأكثر.
- **تتبع التقدم:**
  - نسبة ما استكشفه الطالب من كل جهاز، ودقة إجاباته في كل جهاز.
  - تنبيه إلى نقاط الضعف، وسجل بالنتائج السابقة.
- **المفضلة والملاحظات:** ملاحظات شخصية على أي جزء، وأجزاء مفضلة، ومناظر محفوظة.
- **وضع المعلّم:**
  - ينشئ المعلم درساً من مناظر يختارها بنفسه مع شرح لكل خطوة، ويحفظه في ملف `.ha3d.json` يرسله لطلابه.
  - يمكن عرض الدرس بـ**وضع العرض** بملء الشاشة على شاشة الصف.

### الاحترافية
- **صوت عربي احترافي** لأسماء الأجزاء والدروس والأوصاف.
- **واجهة بلغتين** (عربي وإنجليزي)، مع تكبير الخط وتصغيره، ووضع فاتح أو داكن.
- **وضع جودة منخفضة** للأجهزة الضعيفة.
- **تحديث تلقائي** من صفحة Releases في GitHub، ويعمل في نسخة المثبّت فقط.
- **تراخيص موقّعة دون إنترنت:**
  - فردي شهري أو سنوي، أو **ترخيص مؤسسة لعدة أجهزة**.
  - فترة تجريبية مدتها 5 أيام.
- **حماية الملفات:** النماذج والتسجيلات الصوتية مشفّرة داخل البرنامج المثبّت بتشفير AES-256-GCM.

## التحميل

كل دفعة (push) تشغّل GitHub Actions، فيبني البرنامج على ويندوز. لتحميله افتح تبويب **Actions** ثم **Build Windows EXE**، وحمّل الملف المرفق **HumanAnatomy3D-windows**. بداخله نسخة محمولة (portable) ومثبّت (setup).

## نظام التراخيص (اشتراك شهري أو سنوي)

يعمل نظام التراخيص دون إنترنت ودون أي خادم، بمفاتيح موقّعة رقمياً بخوارزمية ECDSA P-256:

1. عند أول تشغيل تبدأ **فترة تجريبية مدتها 5 أيام**. بعد انتهائها يظهر للمستخدم **معرّف الجهاز** (مثل `DDC5-498C-8050-9905`)، مع زرّي تواصل عبر واتساب والبريد الإلكتروني.
2. يرسل العميل معرّف جهازه. افتح `tools/license-generator.html` في المتصفح وحمّل فيه ملف المفتاح الخاص `private.jwk.json`، ثم أدخل اسم العميل ونوع الاشتراك (شهري أو سنوي أو تاريخ مخصص) ومعرّف الجهاز.
3. أرسل للعميل المفتاح الناتج `HA3D1-...` أو ملف `.lic`. يفعّله العميل من نافذة الترخيص 🔑، فيعمل حتى تاريخ الانتهاء المكتوب فيه، وعلى جهازه فقط.
4. **ترخيص المؤسسات:** لمدرسة أو جامعة، أدخل في خانة الجهاز معرّفات كل الأجهزة، كل معرّف في سطر، فيعمل المفتاح الواحد على جميعها.

- **ترخيص الموظفين:** يوجد خيار داخلي لإصدار ترخيص بلا تاريخ انتهاء.
- **المفتاح الخاص سري:** لا يوجد في المستودع ولا يُرسل للعملاء. من يملكه يستطيع إصدار تراخيص.
- **المفتاح العام:** موجود في `license-public.jwk.json`، ويستخدمه البرنامج للتحقق من التراخيص.
- **تعطيل النظام:** ضع `"enabled": false` في الملف `licensing.config.json`.

## إصدار تحديث للعملاء

1. ارفع رقم الإصدار `version` في الملف `package.json`، مثلاً إلى `5.1.0`.
2. ادفع وسماً (tag) بالرقم نفسه:
   ```bash
   git tag v5.1.0 && git push origin v5.1.0
   ```
3. يبني GitHub Actions الملفات وينشرها في صفحة Releases، ومعها الملف `latest.yml`.
4. يجد البرنامج المثبّت عند العملاء التحديث تلقائياً، ويثبّته عند إغلاقه.

> **ملاحظة:** التحديث التلقائي يحتاج أن تكون صفحة Releases في المستودع عامة. إذا كان المستودع خاصاً، يحتاج النظام إلى خادم تحديث منفصل.

## التشغيل من المصدر

```bash
npm install
npm start          # تشغيل البرنامج
npm run dist       # بناء ملفات exe (يحتاج ويندوز أو Wine لبناء المثبّت)
```

### إعادة توليد النماذج من المصدر

```bash
# 1) حمّل isa_BP3D_4.0_obj_99.zip وpartof_BP3D_4.0_obj_99.zip وملفات القوائم (*.txt) من BodyParts3D، وفك ضغطها في مجلد
pip install numpy fast-simplification scipy trimesh
python3 tools/bp3d_index.py <bp3d_dir>
python3 tools/convert_bp3d.py <bp3d_dir> <out_dir>   # ينتج anatomy.bin وanatomy-parts.json
python3 tools/merge_i18n.py                          # يدمج الأسماء والأوصاف العربية والإنجليزية
```

### إعادة توليد التسجيلات الصوتية

مفتاح ElevenLabs لا يُحفظ في المستودع ولا يُضمَّن في البرنامج، وإنما يُمرَّر عبر متغير البيئة `ELEVENLABS_API_KEY`:

```bash
ELEVENLABS_API_KEY=... python3 tools/tts_elevenlabs.py jobs.json --budget 30000
```

حيث يحتوي `jobs.json` على قائمة بالصيغة `[{"text": "..."}]`. ينتج الأمر ملفات `src/assets/voice/*.mp3` ويحدّث الملف `src/assets/voice.json`.
